# StudySync 

StudySync is a simple and modern educational website designed to make learning easy and engaging.

## Features
- Clean and modern design
- Learning features section
- Testimonials section
- Newsletter section
- Easy navigation
- Responsive layout

## Technologies Used
- HTML
- CSS

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.
